# FileTransfer2

ファイルやフォルダのコピー・移動・削除と、リリース作業（配置・退避・復元）を、一覧に並べて上から順に実行する Windows のツールです（.NET Framework 4.8 / WinForms）。

教材としても使えるよう、シンプルで読みやすい作りを優先しています。

## できること

| グループ | 処理種別 | 用途 |
|---|---|---|
| ふだんのファイル操作 | コピー・移動・削除 | テストデータの入れ替えなど。何度でも上書きする |
| リリース用 | 配置・退避・復元 | 本番の入れ替えと切り戻し。2回実行しても結果が変わらない（冪等） |

- 一覧をプロファイル（TSV）として保存・読み込みできる。退避と配置だけのプロファイルからは、「復元用を作成」ボタンで元に戻すためのプロファイルを作れる
- Plan フォルダに置いた計画ファイルを自動で実行できる
- 設定・文言・禁止パスは、プログラムを直さずにファイルで変えられる

## 動かし方

1. `FileTransfer2.sln` を Visual Studio で開いてビルドする（設定ファイルは exe の横にコピーされる）
2. `FileTransfer2\bin\Debug\FileTransfer2.exe` を起動する
3. 設定は exe の横の `settings.config` で変える（[利用者ガイド 12章](docs/user-guide.md#12-設定ファイル)）

配布するときは、`bin\Debug`（または `bin\Release`）のフォルダごとコピーすれば動きます（インストール不要）。
