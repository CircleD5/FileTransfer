# 「配置」のときに、本番フォルダの中で残すものの一覧（1行に1つの絶対パス）
#
# 配置は、本番フォルダを退避してから、新しい版で入れ替えます。
# ここに書いたものは入れ替えず、その場に残します（動かさないので、アクセス権や作成日時も変わりません）。
# 退避もされるので、復元すると、配置する前の状態に戻ります（復元する直前の状態は .rolledback_日時 に残ります）。
# 向いているもの：業務データ、ログ、本番用の設定ファイルなど
#
# ・パスは絶対パスで書きます（例：D:\App\Data）。相対パスはエラーになります。
# ・配置先フォルダの中にあるものだけが使われます。ほかの配置先のものは無視されるので、
#   1つの一覧に、すべての配置先の分をまとめて書けます。
# ・フォルダを書くと、中身ごと残ります。
# ・新しい版に同じ名前のものがあっても、本番のものが残ります（新しい版のものは置きません）。
#   ただし、本番になかったもの（初めての配置など）は、新しい版のものが置かれます。
# ・退避もせず、一切触りたくないもの（重いもの、アクセス権の関係で動かしたくないもの）は、
#   ここではなく forbidden_paths.txt に書きます。
# ・大文字・小文字は区別しません。* などのワイルドカードは使えません。
#
# 例：
# D:\App\settings.config
# D:\App\Logs
# D:\App\Data
