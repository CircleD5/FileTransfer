# 「配置」のときに、本番フォルダに残すものの一覧（1行に1つ）
#
# 配置は、本番フォルダをまるごと退避してから新版で入れ替えます。
# ここに書いたものだけは、入れ替えた後に退避から戻すので、本番のものがそのまま残ります。
# （例：本番用の設定ファイル、ログ、利用者のデータなど）
#
# ・配置先フォルダから見た相対パスで書きます。フォルダを書くと中身ごと残ります。
# ・本番になかったもの（初めての配置など）は、新版のものが置かれます。
# ・大文字・小文字は区別しません。* などのワイルドカードは使えません。
# ・すべての「配置」の行で共通です。
#
# 例：
# settings.config
# Logs
# Data\user.db
