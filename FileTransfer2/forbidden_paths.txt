# どの処理でも触らない場所の一覧（1行に1つの絶対パス）
#
# ここに書いた場所と、その中にあるものは、どの処理でも触りません（読む・書く・移動・削除のどれもしません）。
# 行はエラーにならず、その場所だけを避けて実行します。避けたことは、ログに場所ごとに1行出ます。
#   例：C:\Windows を書くと、C:\Windows\Temp へのコピーも、C:\ の削除での C:\Windows も避けられる
#   例：配置先 D:\App の中の D:\App\Runtime を書くと、配置でも復元でも Runtime はそのまま残る（退避もされない）
#
# ・パスは絶対パスで書きます（例：C:\Windows）。相対パスはエラーになります。
# ・C:\ のようにドライブごと書くと、そのドライブでは何もできなくなります。
#   できるだけ、触りたくないフォルダを絞って書いてください。
# ・大文字・小文字と末尾の \ は区別しません。* などのワイルドカードは使えません。

C:\Windows
C:\Program Files
C:\Program Files (x86)
